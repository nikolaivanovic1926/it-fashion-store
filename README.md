# IT Fashion Store

E-commerce web application for online clothing shopping, built with React and Vite from a Figma design.

## Features

- Home page with promotions and categories
- Shop page with products loaded from an API
- Product details page
- Shopping cart and checkout
- Login and registration pages
- About Us page

## Technologies

React, Vite, JavaScript, React Router, Context API, HTML, CSS, Git and GitHub

## Project structure

- src/components: Header, Footer and Layout
- src/context: CartContext and AuthContext
- src/api: apiClient.js for communication with the server
- src: pages (Home, Shop, ProductDetails, Cart, Checkout, Login, Register, AboutUs)

## Run locally

1. npm install
2. npm run dev
